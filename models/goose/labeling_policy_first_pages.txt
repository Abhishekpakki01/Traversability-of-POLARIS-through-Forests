Semantic Segmentation
All images have to be labeled pixel-wise; the same holds for 3D point clouds.
Instances-Wise Labeling
Classes that are marked red have to be labeled instance-wise with aninstance_id.
Example: For an image with multiple cars one has to usecar 0, car 1, car 2
etc. In the case of labeling a sequence where the same object can be found in
consecutive frames one should use the sameinstance_id for the object.Example:
car 0should have the sameinstance_id in frame 0 and frame 1. In addition, the
same instance_id should be used for the same object if it is visible in frames of
multiple sensors. Example: Instance-label car 0is used across the frames of all
sensors (LiDAR, camera1, camera2 and so on).

ID#2: snow rgb(209,87,160) ■
Snow that covers surfaces and objects in the winter should be annotated as snow
(■). We want to avoid labeling too many small patches as snow since this could
obscure the underlying object or surface. Therefore, only clearly visible snow patches
of 150 px2 in area should be annotated as snow.
Figure 2.1:Annotation examples of snow (■).
